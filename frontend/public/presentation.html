The Operational Challenge

Current System Bottlenecks

Field officers and department heads currently face severe data access hurdles when attempting to retrieve timely operational insights.

100-Record Capping Limit
Existing administrative UI tables strictly truncate database results at 100 preview rows, rendering large dataset analysis (e.g. 57,000+ water complaints) impossible without IT intervention.
Slow Reporting Turnaround
Generating custom cross-departmental reports (e.g. Ward vs. Officer performance) requires manual SQL script writing by database engineers, taking 48 to 72 hours per request.
Zero Marathi Language Support
Field officers native in Marathi (मराठी) cannot search using local terminology, forcing rigid English keyword matching that misses critical regional complaints.
Manual Data Formatting
Officers are forced to manually copy-paste raw database dumps into Excel to generate basic bar charts and monthly trend lines.
The Intelligent Solution

PMC Assistant Architecture

An end-to-end conversational AI engine built specifically for Pune Municipal Corporation governance datasets.

Bilingual Text-to-SQL
Translates complex Marathi and English questions directly into optimized PostgreSQL queries using LOWER() pattern matching across wards, departments, and officers.
DataGrip Server Pagination
Dynamic server-side pagination (1-25 of 98,726 records) allowing smooth navigation through thousands of rows with instant page loading.
Auto-Charting & Visuals
Automatically renders Bar Charts, Line Trends, and Pie Charts dynamically based on query context without manual configuration.
Technology Stack

Enterprise Infrastructure & Models

Built on open-source foundation models and high-performance asynchronous web architecture.

Core Technical Stack
  • ⚡ Backend API: FastAPI + Python 3.12 (Asynchronous AsyncIO)
  • 💾 Database Layer: PostgreSQL Engine + SQLAlchemy ORM
  • ⚛️ Frontend UI: React 18 + TypeScript + Vite + Vanilla CSS
  • 🤖 Agent Framework: Vanna AI 2.0 Agentic Architecture
  • 🔌 Protocol Integration: FastMCP Server (Model Context Protocol)
LLM Open-Source Model Stack
  • 🦙 Primary LLM: meta-llama/llama-3.3-70b-instruct via OpenRouter
  • ⚡ Fallback Model 1: google/gemini-2.5-flash
  • 💻 Fallback Model 2: qwen/qwen-2.5-coder-32b-instruct
  • 🔒 Data Security: Zero retention on proprietary servers; 100% compliant with PMC security mandates.
